> This is a sample post. It exists to show what Markdown and MDC (Markdown Components) look like once rendered, so future posts are easy to write.

This is where we'll share **press mentions**, _platform updates_, and general news about Scholar Data. Every post here is just a `.md` file in `content/announcements/`.

## Writing a new post

Add a new Markdown file to `content/announcements/`, prefixed with a number to control its order (the number itself won't show up in the URL):

```bash
content/announcements/02.nih-s-index-challenge.md
```

Every post needs frontmatter with a `title`, `description`, and `date`:

```md [content/announcements/02.nih-s-index-challenge.md]
---
title: We took first place in the NIH S-Index Challenge
description: A quick recap of the win and what it means for the platform.
date: 2026-01-15
---

Full write-up goes here...
```

This post is automatically picked up by [content.config.ts](/) and appears on the [Announcements](/announcements) page, newest first.

## Callout components

A few components are available for drawing attention to something inside a post.

<note>

Use `note` for general context or a pointer to related content.

</note>

<tip>

Use `tip` for a helpful suggestion.

</tip>

<warning>

Use `warning` for something readers should be careful about.

</warning>

<callout icon="i-heroicons-megaphone" to="/announcements">

Use `callout` for a highlighted link - like sending readers back to the full announcements list.

</callout>
