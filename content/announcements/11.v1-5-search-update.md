---
title: "v1.5: Search update"
description: DOIs and ORCID iDs are no longer automatically searched as an exact match, and search results now save their page number in the URL.
date: 2026-08-19
---

We have removed automatic exact-match detection for DOIs and ORCID iDs in search. Pasting one of these identifiers into search will now be matched the same way as any other search term. If you want an exact match, wrap your search term in quotes, e.g. "10.5061/dryad.abc123".

We have also updated search so that the current page number is saved in the URL. This means you can now share or bookmark a link to a specific page of search results, and refreshing or navigating back will return you to the page you were on.
