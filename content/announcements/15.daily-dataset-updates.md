Scholar Data now adds newly published datasets on a daily schedule. Instead of waiting for periodic bulk updates, new records flow into search, dataset pages, and researcher profiles every day.

## The one-week buffer

We intentionally process datasets with a one-week delay after they are published. This gives metadata registries time to settle and lets us capture early corrections before a dataset is indexed and scored. In practice, a dataset you publish today should appear on Scholar Data within about a week.

If a dataset still hasn't shown up after that window, check back the next day, as updates are processed continuously.
